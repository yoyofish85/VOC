# 标注规范与标签体系说明（V3）

## 1. 标准标签文件

- **Excel 与 CSV**：`output/standard_label_system_for_annotators.xlsx`、`output/standard_label_system_for_annotators.csv`
- 由 `label_project/export_standard_label_system.py` 根据 `label_hierarchy_final.json` 与 `gold_l3_clusters_v3.json` 生成。
- 字段包含：
  - **一级 / 二级 / 三级（体系标准）**
  - **体系频次**（来自 hierarchy 详情）
  - **聚类分组 ID、同义词、关键词**（来自 5628 金标聚类）

## 2. 一级 / 二级 / 三级含义

| 层级 | 说明 |
|------|------|
| 一级 | 产品质量类 / 服务类 / 体验需求类；**离线锁定**以规则与清洗 MD5 为准 |
| 二级 | 业务二级，**白名单**来自金标统计 + 全体系补全；精排可经 Qwen 仅在名单内 |
| 三级 | 先走**原体系标签列表**，再走**聚类 canonical**，再走 LLM |

## 3. 线上导入（可选）

若希望复核页展示 **V3 结构化标签**，请在导入 CSV 中增加列 **`v3_label_meta`**（JSON 字符串），示例：

```json
{
  "l1": "产品质量类",
  "l2": "座舱问题",
  "l3": "导航异常",
  "match_type": "cluster_l3",
  "confidence": 0.63,
  "clean_hit": false,
  "l3_source": "cluster"
}
```

也可使用列名 **`标签体系JSON`**（与 `v3_label_meta` 等价）。

## 4. 一键更新白名单与聚类

- Mac：**双击** `label_project/update_clean_data.command`
- 或终端：`cd label_project && ./run_label_update.sh`
- 需准备：`testdata3.csv`（或环境变量 `LABEL_GOLD_CSV`）、`data_clean_project/data_clear.csv`（清洗库）
