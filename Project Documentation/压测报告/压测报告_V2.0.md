| 优化项 | 说明 |
|--------|------|
| 严重故障词 | 48个（故障、异响、死机、黑屏等） |
| 优先级 | 最高优先级，任何出现直接判定为产品质量问题 |
| 置信度 | 0.9+ (根据匹配词数量累加) |

### 2.2 LLM验证模块

- **触发条件**：关键词置信度 0.7-0.9 或 无关键词匹配
- **验证策略**：
  - 关键词与LLM一致 → 取高置信度
  - 关键词与LLM冲突 → 取LLM结果
- **调用优化**：高置信度（≥0.9）直接返回，不调用LLM

### 2.3 Few-shot学习支持

- **数据源**：testdata2_fixed.csv（2326条）
- **示例数量**：每类2条，共8条
- **集成方式**：内置于LLM调用函数
