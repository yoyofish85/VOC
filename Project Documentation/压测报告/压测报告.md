## 五、问题分析

### 5.1 主要问题

1. **词库严重不足**
   - 每个分类只有20个关键词
   - 101条数据无法通过关键词匹配 (20.8%)

2. **分类边界模糊**
   - 体验需求容易被误判为产品咨询 (33条)
   - 产品质量问题容易被误判为销售服务问题 (67条)

3. **大模型效果不明显**
   - 关键词模式: 39.79%
   - 大模型模式: 40.00%
   - 差异仅0.21%

## 六、改进建议

### 6.1 词库扩充 (优先级: 高)

目标: 每个分类至少100个关键词

建议关键词来源:
- 从历史数据中自动提取
- 参考竞品分析报告
- 行业术语词典

### 6.2 分类映射优化 (优先级: 中)

- 体验需求 vs 产品咨询: 区分"建议"类和"咨询"类
- 产品质量问题: 细分二级分类

### 6.3 Prompt优化 (优先级: 中)

增强大模型Prompt:
```python
prompt = """
你是新能源车企舆情分类专家。请严格按以下5类分类：
- 产品质量问题：车辆硬件/软件故障、安全问题、性能问题
- 销售服务问题：售后服务、门店服务、交付问题
- 产品咨询：价格咨询、配置咨询、功能咨询
- 体验需求：功能建议、优化建议、体验改进
- 非问题：表扬、感谢、好评

注意区分：
- "希望/建议/希望增加" = 体验需求
- "能不能/是否可以/怎么" = 产品咨询
- "故障/异响/死机/黑屏" = 产品质量问题
"""
```
