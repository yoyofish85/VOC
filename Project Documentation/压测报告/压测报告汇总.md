## 三、各版本详细报告

### 3.1 V1.5 初始版本

**测试数据**：testdata.csv (485条)

| 指标 | 结果 | 问题 |
|------|------|------|
| 关键词模式准确率 | 39.79% | 词库严重不足 |
| 大模型模式准确率 | 40.00% | Prompt未优化 |
| 覆盖率 | 79.2% | 20.8%无法分类 |
| 错误集中 | 产品质量→未分类:85条 | 词库仅100个 |

**核心问题**：
- 每类只有20个关键词
- 分类边界极度模糊
- 大模型完全没发挥作用

---

### 3.2 V1.5.1 词库扩充版

**优化措施**：
- 每类关键词扩充至≥100个
- 添加边界判断规则
- 优化LLM Prompt

| 指标 | 结果 | 提升 |
|------|------|------|
| 关键词库 | 993个 | +893个 |
| 准确率 | 62.92% | +23.13% |
| 覆盖率 | 99.0% | +19.8% |

---

### 3.3 V1.6 精细化边界版

**优化措施**：
- 引入权重+优先级机制
- 充电设施专属规则
- 非问题类优先判定

| 指标 | 结果 | 问题 |
|------|------|------|

### 4.1 成功经验

| 经验 | 说明 | 版本 |
|------|------|------|

## 五、技术架构

### 5.1 系统架构

```
┌─────────────────────────────────────────────────────────┐
│                    数据接入层                             │
│  CSV上传 → 自动去重 → 格式校验 → 时间字段映射            │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                    分类处理层                             │
│  关键词匹配 → 置信度计算 → LLM验证 → 边界规则            │
│  (权重+优先级)    (≥0.9直接返回)  (0.5-0.9区间)        │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                    人工复核层                            │
│  双列布局 → 批量操作 → 分类依据 → 保存修正              │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                    归档导出层                            │
│  年度+月度归档 → 按分类分Sheet → 多维度追溯             │
└─────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────┐
│                    可视化分析层                          │
│  趋势图 → 饼图 → 关键词云 → 预警模块                    │
└─────────────────────────────────────────────────────────┘
```

### 5.2 混合分类策略

```
Step 1: 关键词匹配（置信度≥0.9）→ 直接分类
Step 2: 置信度0.5-0.9 → 调用LLM交叉验证
Step 3: 置信度<0.5 → 标记待人工复核
```

### 5.3 边界规则优先级

```
最高优先级：故障词（异响/黑屏/死机/故障）→ 产品质量问题
高优先级：建议词（希望/建议/优化）+无故障 → 体验需求
中优先级：服务词（售后/门店/交付）+无故障 → 销售服务问题
最高优先级：非问题词（表扬/感谢/好评）→ 非问题
```
