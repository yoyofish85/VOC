## 三、新手引导优化

### 3.1 引导流程

**3步核心操作**：
1. **上传数据** - 在"数据接入"上传CSV文件
2. **智能分类** - 点击"智能分类"自动处理
3. **人工复核** - 审核并修正分类结果

### 3.2 触发方式

- 侧边栏点击"❓ 新手引导"按钮
- 首次使用时自动弹出
