## 三、核心功能使用说明

### 3.1 数据接入（上传CSV）
1. 进入系统后，点击"数据接入"导航
2. 点击"选择CSV文件"上传舆情数据
3. 系统自动校验格式，支持"舆情时间"或"舆情日期"字段
4. 上传成功后自动跳转至"分类处理"页面

**CSV格式要求**：
- 必须包含：`舆情中文` 或 `反馈内容` 字段
- 时间字段：`舆情时间` 或 `舆情日期`（至少有一个）

### 3.2 智能分类
1. 在"分类处理"页面，确认待分类数据
2. 点击"🚀 开始智能分类"按钮
3. 系统采用混合分类策略：
   - **关键词模式**：优先匹配关键词库，置信度≥0.9直接返回
   - **模型模式**：关键词匹配失败时调用本地Ollama模型
4. 分类完成后显示统计信息

### 3.3 人工复核
1. 进入"人工复核"页面
2. 左侧为舆情列表，右侧为详情编辑区
3. 点击任意一条舆情，详情区自动更新
4. 可进行的操作：
   - 修改"人工修正结果"下拉框
   - 添加备注信息
   - 点击"💾 保存修正"保存单条修改
   - 批量标记已复核

**分类依据说明**：
- 关键词分类：显示匹配的具体关键词
- 模型分类：显示模型判断理由

### 3.4 归档导出
1. 在"人工复核"页面完成复核后
2. 点击底部"💾 归档到年度总表"按钮
3. 系统自动按年月归档，并按分类分Sheet存储
4. 进入"归档导出"页面查看历史归档
5. 支持"全部"选项查看汇总数据

### 3.5 舆情分析
1. 进入"舆情分析"页面
2. 可选择时间维度：日/周/月
3. 查看可视化图表：
   - 📈 趋势图：分类数量随时间变化
   - 🥧 饼图：各分类占比
   - 🔤 高频关键词TOP10
4. 查看预警信息

## 四、分类逻辑说明

### 4.1 五类分类定义

| 分类 | 说明 | 典型关键词 |
|------|------|-----------|
| 产品质量问题 | 车辆/充电设施硬件软件故障 | 异响、黑屏、故障、充电桩故障 |
| 销售服务问题 | 售后、门店、交付服务问题 | 售后、门店、交付、等待 |
| 产品咨询 | 价格/配置/功能咨询 | 价格、配置、如何、能不能 |
| 体验需求 | 功能/体验优化建议 | 建议、希望、优化、增加 |
| 非问题 | 表扬、感谢、好评 | 感谢、满意、推荐 |

### 4.2 混合分类策略

```
Step 1: 关键词匹配（置信度≥0.9）→ 直接分类
Step 2: 置信度0.5-0.9 → 调用LLM交叉验证
Step 3: 置信度<0.5 → 标记待人工复核
```

### 4.3 边界规则优先级

```
最高优先级：故障词（异响/黑屏/死机/故障）→ 产品质量问题
高优先级：建议词（希望/建议/优化）+无故障 → 体验需求
中优先级：服务词（售后/门店/交付）+无故障 → 销售服务问题
最高优先级：非问题词（表扬/感谢/好评）→ 非问题
```

## 八、常见问题

### Q1: 上传CSV提示"缺失舆情时间"
**A**: 检查CSV是否包含"舆情时间"或"舆情日期"字段，至少需要一个。

### Q2: 归档后数据量不对
**A**: 系统会自动去重（基于反馈时间+反馈内容），相同数据只保留一条。

### Q3: 图表中文显示方格
**A**: 系统已自动检测可用中文字体，确保系统安装了Songti SC/Heiti TC/PingFang SC等字体。

### Q4: 人工复核详情不更新
**A**: 点击列表中的舆情后，系统会自动刷新详情区。

### Q5: 归档只有16条
**A**: 归档默认只处理"已复核"状态数据，已修改为支持"已复核/未复核/待复核"状态都进行归档。
