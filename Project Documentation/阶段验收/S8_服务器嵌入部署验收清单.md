# S8 旧服务器：嵌入模型部署与共存验收清单

## 目标

在旧服务器（14B 生产）部署 `bge-m3`（或等效），**离线**写 `opinion_embedding` 表并跑跨 L2 聚集；**不**进入分类热路径。

## 前置

- [ ] 已推送含 S8 的 commit（见进展记录）
- [ ] 按离线协议生成带 `VERSION_MANIFEST.txt` 的更新包
- [ ] 确认磁盘可容纳 ~1.2GB 模型

## 步骤

1. **拉模型（有网时段或离线拷贝 GGUF）**
   ```bash
   ollama pull bge-m3
   ollama list | grep -i bge
   ```
2. **确认与 14B 共存**
   ```bash
   ollama list   # 同时可见 qwen*14b* 与 bge-m3
   # 抽测分类延迟：跑一小批规则/14B 分类，对比部署前后耗时
   ```
3. **离线嵌入 + 聚类（只写 embedding 库）**
   ```bash
   export VOC_EMBED_MODEL=bge-m3
   python3 performance_evaluation/run_complaint_clusters.py \
     --db src/backend/opinion_review.db \
     --prefer-ollama --limit 400
   ```
4. **验收**
   - [ ] `opinion` 表分类字段未被改写（可用前后 checksum / 行数）
   - [ ] `opinion_embedding.db`（或同库 `opinion_embedding` 表）有向量
   - [ ] 输出中至少 1 个 `cross_l2=true` 簇
   - [ ] 人工抽检簇纯度 ≥80%（在 CSV 标注）
   - [ ] 生产批量分类延迟无明显上升（嵌入仅批跑）

## 回滚

- 停用批跑脚本即可；删除/停用 `bge-m3` 不影响 14B 分类。
- 可删 `opinion_embedding.db`，分类库不动。
