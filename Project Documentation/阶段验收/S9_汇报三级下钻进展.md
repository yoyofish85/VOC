## 这块是干什么的（直白版）

把库里的客诉按「汇报主题」归堆：先看哪个主题客诉多，再点进去看具体问题分类（三级标签）和脱敏后的原始留言，并可导出 CSV 给汇报用。

界面名称：**客诉主题台账**（原「主题证据链」）。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/report/themes` | 主题列表 + 环比/趋势 + empty_hint |
| GET | `/api/report/themes/{id}` | L3 构成 + 代表原文 |
| GET | `/api/report/themes/{id}/opinions` | 分页明细（脱敏） |
| GET | `/api/report/themes/{id}/export.csv` | CSV 导出（脱敏） |
