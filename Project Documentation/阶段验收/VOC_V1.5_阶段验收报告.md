## 1. 验收目的

对 VOC_V1.5 当前阶段交付成果进行**范围确认、质量确认与可运维性确认**，作为阶段性收口依据，便于后续迭代或上线评审引用。

## 2. 验收范围

### 2.1 业务功能

- **数据导入**：CSV 上传、编号与原文 MD5 去重、导入统计与提示文案。
- **智能分类**：规则/聚类路径；大批量异步分类与任务状态查询；可选 LLM 深度分类（环境依赖 Ollama）。
- **人工复核**：一级可修正、二级白名单与可搜索下拉、三级关键词展示；单条/批量确认与**暂存**（写库为已复核并支持回流）。
- **数据回流**：复核结果写入清洗库（`data_clear.csv`）、关键词与金标策略（测试环境可隔离）；年度归档接口。
- **前端工作台**：数据概览与图表、复核列表筛选分页、与后端 API 联调。

### 2.2 非功能与工程能力

- **性能与大样本**：列表分页、标签体系批量接口、上传与分类异步化；独立测试库与回流目录隔离变量。
- **跨域与安全**：CORS 配置覆盖常见本地与局域网来源。
- **自动化测试**：以接口测试为主、Playwright 黄金路径为辅；`app_launcher.py --verify` 一键拉起服务并生成报告。

### 2.3 不在本阶段验收范围内（可单列后续阶段）

- 生产环境部署架构、监控告警、账号权限体系。
- LLM 效果与准确率专项评测（需独立评测集与基线）。
- 全量浏览器兼容性矩阵（当前以 Chromium E2E 为代表）。

## 4. 验收标准与验证方式

| 编号 | 验收项 | 标准 | 验证方式 |
|------|--------|------|----------|
| A1 | 服务可用 | 健康检查返回成功 | `GET /health` 或 `GET /api/health` |
| A2 | 导入与去重 | 重复数据跳过计数正确，大样本可完成上传 | 接口测试 + 可选 5628 条慢用例 |
| A3 | 分类 | 无 LLM 路径稳定写回 `v3_label_meta` | `tests/test_review.py` |
| A4 | 暂存与状态 | 暂存后 `review_status` 为已复核，刷新不丢 | 接口测试 + E2E |
| A5 | 回流与归档 | 已复核批次可归档；测试库下清洗库文件可校验 | `tests/test_review.py`（隔离目录） |
| A6 | 自动化门禁 | 一键验证可通过 | `python3 app_launcher.py --verify` |
| A7 | E2E | 黄金路径通过 | Playwright：`tests/test_e2e.py`（状态文案兼容「已复核 / 已复核（历史）」） |

**说明**：执行全量 `--verify` 前需保证 **后端端口 8000、前端端口 8080** 未被占用（或与脚本约定一致）；若仅跑接口快速门禁，可使用 `--verify --quick` 等参数（以仓库内 `app_launcher.py` 注释为准）。

## 5. 验收结论

- **功能完整性**：本阶段约定范围内的导入、分类、人工复核、暂存持久化、归档与回流链路**可验收**。
- **质量门禁**：仓库内自动化测试与一键验证流程**可作为阶段收口门禁**；通过情况以最近一次 `reports/report.html` 与 `reports/junit.xml` 为准。
- **遗留与建议**：生产部署、LLM 专项评测、多浏览器回归建议在后续阶段单独立项。
