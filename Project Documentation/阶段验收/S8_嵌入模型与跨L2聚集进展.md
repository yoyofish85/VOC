## 降级策略（已实现）

1. **优先**：Ollama `bge-m3`（`VOC_EMBED_MODEL`，`--prefer-ollama`）
2. **开发机/无模型**：`HashingEmbedder`（确定性 char n-gram）
3. **再降级**：`--keyword-fallback`（`root_cause_hint`/L3 共现）

## 复跑命令

```bash
# 开发机打通（当前默认无 bge-m3）
python3 performance_evaluation/run_complaint_clusters.py --force-hashing --limit 400

# 服务器有 bge-m3 后
VOC_EMBED_MODEL=bge-m3 python3 performance_evaluation/run_complaint_clusters.py --prefer-ollama --limit 400
```

向量库默认：`src/backend/opinion_embedding.db`（与 `opinion_review.db` 并列，`*.db` 已 gitignore）。
