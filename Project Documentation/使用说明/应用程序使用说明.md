# 舆情复核系统 V1.5 - 应用程序使用说明

## 快速开始

### 方法一：直接运行启动器（推荐）

在项目根目录（本仓库为 `VOC_V1.5`）执行：

```bash
cd "/Users/yuchao/Documents/AI Agent/VOC_V1.5"
python3 app_launcher.py
```

系统会自动：

1. 启动后端服务（`http://localhost:8000`，`backend/main.py`）
2. 启动前端开发服务（`http://localhost:8080`，`npm run dev`）
3. 约 2 秒后尝试打开浏览器
4. 退出时（Ctrl+C 或关闭终端）触发清理逻辑；复核数据已写入 SQLite，无需额外「保存到文件」步骤

**结论**：改动后**仍用同一套启动方式**，仅项目路径与版本号与旧文档中的 `VOC_V1.3` / V1.3 不同。

---

### 方法二：打包成 macOS 应用程序（可选）

当前仓库**未包含** `create_app.sh` / PyInstaller 配置时，方法二可能不可用。若你本地保留旧版打包脚本，可在**本仓库根目录**按原流程自行适配路径与应用名称后使用；否则请优先用方法一。

## 界面说明（V1.5 三级标签）

导入的 CSV 若含 **`v3_label_meta`**（JSON），复核页「模型分类结果」列会以 **一级锁定 / 二级白名单 / 三级** 分行展示，并显示匹配方式、置信度、三级来源等；**无该字段**时自动回退为旧版「分类 + 关键词」两行展示。前端实现见 `frontend/src/components/OpinionReview.vue`。

## 功能说明

### 自动保存机制

系统会在以下情况自动保存数据：

| 场景 | 保存内容 |
|-----|---------|
| 复核操作 | 实时保存到 SQLite 数据库 |
| CSV 导入 | 自动去重并保存 |
| 关键词学习 | 实时更新词库 |
| 程序关闭 | 自动执行保存确认 |

### 数据存储位置

| 数据类型 | 存储位置 |
|---------|---------|
| 复核数据 | `backend/opinion_review.db`（含 `v3_label_meta` 等新列时由迁移自动追加） |
| 关键词词库 | `backend/keywords_v1.2.json` |
| 分类日志 | `backend/classification_accuracy.log` |
| 前端构建产物 | `frontend/dist/`（开发调试时启动器走 Vite，不强制先 build） |

## 故障排除

### 1. 端口被占用

```bash
# 查看占用端口的进程
lsof -i :8000
lsof -i :8080

# 或者直接运行启动器，它会自动处理
python3 app_launcher.py
```

### 2. 依赖缺失

```bash
# 安装后端依赖
cd backend
pip3 install -r requirements.txt

# 安装前端依赖
cd ../frontend
npm install
```

### 3. 前端无法启动

确保 Node.js 版本 >= 14：

```bash
node --version
npm --version
```

### 4. 浏览器无法打开

手动访问：http://localhost:8080

## 常见问题

**Q: 关闭程序后数据会丢失吗？**
A: 不会。数据实时保存到 SQLite 数据库，关闭时也会确认保存。

**Q: 可以同时运行多个实例吗？**
A: 不建议，端口会被占用导致启动失败。

**Q: 如何备份数据？**
A: 复制 `backend/opinion_review.db` 文件即可。

**Q: 前端编译很慢怎么办？**
A: 首次编译需要安装依赖，后续会快很多。可以在打包时预先编译。
