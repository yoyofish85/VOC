# 舆情复核系统 V1.5 - 应用程序使用说明

## 快速开始

### 方法一：双启动脚本（服务器推荐，2026-07-08）

项目根目录提供两个互斥启动脚本，**同一时间只运行其中一个**（先 Ctrl+C 停掉再切换）：

| 脚本 | 分类后端 | 说明 |
|------|----------|------|
| `./start_ollama.sh` | Ollama Qwen 14B | 需本机 `ollama serve` 且已 `pull qwen2.5:14b-instruct-q4_K_M` |
| `./start_mlx.sh` | MLX + LoRA | 自动设置 `VOC_USE_MLX=1`；首次会检查/安装 MLX 依赖 |

```bash
cd "/Users/chaoyu/Desktop/VOC_AI agent/VOC_V1.5"   # 服务器示例路径

# 首次部署或重建 Python 环境（需 Python 3.11–3.13，勿用 3.14）
bash scripts/setup_server_venv.sh

# MLX + LoRA（默认 adapter: ~/lora_adapter_14b_v2）
./start_mlx.sh

# 切换回 Ollama
./start_ollama.sh
```

**说明：**

- `source .venv/bin/activate` **可选**；脚本会自动使用 `.venv/bin/python`。
- 自定义 LoRA 路径：`export VOC_MLX_ADAPTER=~/lora_adapter_14b` 后再执行 `./start_mlx.sh`。
- 首次 MLX 推理加载模型约 **90 秒**（仅首次分类，非启动阶段）。
- 启动成功后会打开 `http://localhost:8080`（前端）与 `http://localhost:8000`（API）。

---

### 方法二：直接运行启动器（开发机）

在项目根目录执行：

```bash
cd "/Users/yuchao/Documents/AI Agent/VOC_V1.5"
python3 app_launcher.py
```

系统会自动：

1. 启动后端服务（`http://localhost:8000`）
2. 启动前端开发服务（`http://localhost:8080`）
3. 约 2 秒后尝试打开浏览器
4. 退出时（Ctrl+C）触发清理；复核数据已写入 SQLite

未设置 `VOC_USE_MLX=1` 时，默认走 **Ollama** 分类路径。

---

### 方法三：打包成 macOS 应用程序（可选）

当前仓库**未包含** `create_app.sh` / PyInstaller 配置时，方法二可能不可用。若你本地保留旧版打包脚本，可在**本仓库根目录**按原流程自行适配路径与应用名称后使用；否则请优先用方法一。

## 功能说明

### 自动保存机制

系统会在以下情况自动保存数据：

| 场景 | 保存内容 |
|-----|---------|
| 复核操作 | 实时保存到 SQLite 数据库 |
| CSV 导入 | 自动去重并保存 |
| 关键词学习 | 实时更新词库 |
| 程序关闭 | 自动执行保存确认 |

### 数据存储位置

| 数据类型 | 存储位置 |
|---------|---------|
| 复核数据 | `backend/opinion_review.db`（含 `v3_label_meta` 等新列时由迁移自动追加） |
| 关键词词库 | `backend/keywords_v1.2.json` |
| 分类日志 | `backend/classification_accuracy.log` |
| 前端构建产物 | `frontend/dist/`（开发调试时启动器走 Vite，不强制先 build） |

## 故障排除

### 1. 端口被占用

```bash
# 查看占用端口的进程
lsof -i :8000
lsof -i :8080

# 或者直接运行启动器，它会自动处理
python3 app_launcher.py
```

### 2. 依赖缺失

**开发机：**

```bash
pip3 install -r requirements.txt
cd src/frontend && npm install
```

**服务器（含 MLX）：**

```bash
bash scripts/setup_server_venv.sh
# 或手动：
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install 'transformers>=5.0.0,<5.13.0'
.venv/bin/pip install -r requirements-mlx.txt
.venv/bin/pip install python-multipart
```

> `transformers` 须 **<5.13**，否则 `import mlx_lm` 会失败；Python 须 **3.11–3.13**（3.14 无 `pydantic` 轮子）。

### 3. MLX 启动失败

| 现象 | 处理 |
|------|------|
| `No module named 'fastapi'` | 勿用系统 `python3`；用 `./start_mlx.sh` 或 `.venv/bin/python` |
| `import mlx_lm` AttributeError | `.venv/bin/pip install 'transformers>=5.0.0,<5.13.0'` 后重试 |
| 缺 `python-multipart` | `.venv/bin/pip install python-multipart` |
| 后台启动超时 / EOFError | 用前台 `./start_mlx.sh`，勿 `app_launcher &` |

### 4. 前端无法启动

确保 Node.js 版本 >= 14：

```bash
node --version
npm --version
```

### 5. 浏览器无法打开

手动访问：http://localhost:8080

## 常见问题

**Q: 关闭程序后数据会丢失吗？**
A: 不会。数据实时保存到 SQLite 数据库，关闭时也会确认保存。

**Q: 可以同时运行多个实例吗？**
A: 不建议，端口会被占用导致启动失败。

**Q: 如何备份数据？**
A: 复制 `backend/opinion_review.db` 文件即可。

**Q: 前端编译很慢怎么办？**
A: 首次编译需要安装依赖，后续会快很多。可以在打包时预先编译。
